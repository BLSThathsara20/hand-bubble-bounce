# Hand Bubble Match

Webcam match-3 bubble shooter controlled with your **index finger**.

- Colored balls hang at the top
- Aim the bottom ball by pointing/dragging with one finger
- Flick upward to shoot
- Match **3+ same colors** to pop; disconnected balls fall
- Adaptive AI raises pressure (more colors, faster new rows)

## Run

```bash
npm install
npm run dev
```

Desktop Chrome or Edge recommended. Allow camera access when prompted.
